# ARCHIC DOMAIN — CATALOGUE / COMMERCE

## Native primitives

- product / vehicle
- category
- variant / configuration
- availability when truthful
- comparison
- enquiry

## Avoid

- badge overload
- hover-only product information
- fake scarcity
- discount theatre
- tiny product images
- identical decorative cards unrelated to item attributes
- unnecessary carousels
- hiding useful information to look premium

## Prefer

- strong real product imagery
- efficient scanning
- clear states
- mobile-friendly CTA behavior
- useful comparison only when supported by real data
- honest availability/configuration language
- enquiry paths tied to actual buying decisions
