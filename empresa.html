Qué ofrece Ciudad del Sol

Tres modalidades para necesidades distintas.

La web no fuerza una misma solución para un evento puntual y para una operación recurrente.

Fabricación, alquiler y venta forman parte de la oferta; la duración y el contexto ayudan a decidir por dónde empezar.

01Alquiler

Para campañas, temporadas, ferias, eventos y otras necesidades de duración limitada.

02Venta

Para operaciones recurrentes en las que disponer de vehículo propio puede tener sentido.

03Fabricación / proyecto

Para necesidades que requieren estudiar una configuración alrededor del servicio previsto.

04Confirmación

Unidad, equipamiento, disponibilidad y alcance se concretan en la propuesta correspondiente.

La modalidad se orienta con información del servicio, no con una promesa genérica.Ver soluciones →

Criterio de trabajo

Primero contexto. Después unidad.

El mismo vehículo no tiene por qué ser la respuesta correcta para todos los recorridos.

Localidad, trayecto aproximado, fechas y tipo de uso permiten orientar la conversación. A partir de ahí se concreta la modalidad y se valida la información del vehículo que corresponda.

01 · Contexto

Dónde debe funcionar y qué necesidad tiene que resolver.

02 · Recorrido

Origen, destino, zona de trabajo o puntos que conviene conectar.

03 · Propuesta

Modalidad, unidad y alcance concretos para continuar el proyecto.

Base real

Écija · Sevilla

Écija aporta algo más útil que una frase corporativa: permite ver un vehículo de Ciudad del Sol dentro de un recorrido real.

El caso publicado conecta la estación de autobuses con la Plaza de España y sirve para mostrar cómo el origen y el destino condicionan la lógica del servicio.

Información responsable

Lo que no está documentado no se convierte en argumento comercial.

Capacidades, homologaciones, configuraciones concretas y disponibilidad se comunican cuando pueden confirmarse para una unidad o propuesta.

Esta forma de presentar la empresa evita que una cifra o una especificación genérica sustituya a la información que realmente necesita cada proyecto.

Una operación concreta necesita una propuesta concreta.

Localidad, fechas aproximadas, recorrido y tipo de uso bastan para empezar.
