Cómo se define un proyecto

El recorrido manda antes que el catálogo.

Un tren turístico no se elige aislado. Primero hay que entender dónde empieza el servicio, qué trayecto debe resolver y durante cuánto tiempo. A partir de ahí se decide vehículo y modalidad.

El mismo vehículo no sirve para todos los recorridos.

Turismo urbano, ferias, recintos privados y operaciones recurrentes plantean necesidades distintas. La solución se organiza alrededor del uso, no de una lista genérica de prestaciones.
